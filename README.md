# 🚗 YOLOv8 UAV Vehicle & Human Detection

Bu proje, **YOLOv8l** mimarisi kullanılarak gerçekleştirilmiş bir nesne tespiti uygulamasıdır. Model, 26.000'den fazla görsel ile eğitilmiş ve yüksek doğruluk oranlarına ulaşmıştır.

## 📊 Veri Seti

Eğitim için kullanılan veri seti şu şekildedir:

- 📷 26.000+ görsel
- 🚗 150.000+ araç etiketi
- 🧍 50.000+ insan etiketi
- 🏍️ 25.000+ motosiklet etiketi

## 🧠 Model

Model olarak **YOLOv8l (large)** sürümü tercih edilmiştir. Modelin eğitimi, Ultralytics YOLOv8 framework’ü kullanılarak yapılmıştır.
